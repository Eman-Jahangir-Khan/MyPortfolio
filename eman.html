Featured project

ArtConnect

A social & portfolio platform for art students and faculty — designed and built independently as my final-year project.

Final-year project
FlutterFirebaseDart

Four roles, one connected system

ArtConnect gives students a place to publish a portfolio and connect with faculty and buyers, while giving faculty and admins the tools to manage classes, submissions, and the community around them — across four distinct user roles: Student, Faculty, Visitor, and Admin.

What it does

  • Role-based dashboards for Students, Faculty, Visitors, and Admins
  • Real-time one-to-one and group messaging, with request-based access control
  • Class scheduling for faculty, with per-student visibility
  • Assignment submission, review, and grading workflow
  • Event Q&A with admin moderation and in-app notifications
  • Buyer purchase inquiries with an admin commission calculator

Engineering decisions

  • Modelled Firestore collections and security rules to enforce role-based access without a paid backend tier
  • Designed a portfolio-eligibility index to gate chat access, since the primary collection's document IDs aren't user UIDs
  • Worked around free-tier Firebase Auth limits with an application-level user blocking system
  • Built a unified, app-wide real-time notification layer spanning chats, event Q&A, and admin replies
